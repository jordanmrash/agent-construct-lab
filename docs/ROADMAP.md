# Roadmap: proposed work, not shipped capability

## Public-contract hardening

Add full schema validation, repair sanitized schema metadata through reviewed changes, and add negative tests for unknown fields and invalid enum values. Acceptance: clean-checkout positive and negative fixtures pass on both CI operating systems.

## Utility portability

Audit every Release 4 utility for external workspace assumptions and make inputs explicit. Acceptance: each documented utility has a public synthetic input and an isolated reproducible run, with no private directories required.

## Platform evidence

Collect independently verifiable target evidence and distinguish declared, mapped, operated and certified states. Acceptance: authentic receipts and negative enforcement cases tied to exact construct and adapter revisions. No target is promoted on a fixture score alone.

## Maintenance

Add result artifacts, dependency review and stronger disclosure checks without hiding scanner blind spots. Acceptance: reproducible gate output and manual publication review. Matching AoR's depth means matching evidence discipline, not importing its private corpus or duplicating its architecture.
